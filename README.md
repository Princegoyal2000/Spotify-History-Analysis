# Spotify Analysis Dashboard | Power BI 🎧📊

## 📌 Project Overview  
This project presents an end-to-end data analysis of Spotify listening patterns using Power BI. The dashboard uncovers deep insights about user engagement across albums, artists, and tracks over multiple years. It was built as part of a data analytics learning initiative to showcase skills in data cleaning, modeling, visualization, and storytelling.

---

## 📂 Features & Highlights

- ✅ Cleaned and transformed raw data using **Power Query**  
- ✅ Built relational data model with defined hierarchies (Album → Artist → Track → Playtime)  
- ✅ Created **DAX measures** for KPIs, YoY analysis, and trend metrics  
- ✅ Designed an interactive and responsive **Power BI dashboard** with:
  - Charts, slicers, and KPIs
  - Drill-down & drill-through capabilities
  - Grid-level view and hourly listening patterns
  - Quadrant analysis for track categorization  
- ✅ Extracted **actionable insights** to support content promotion and user engagement strategy  

---

## 📊 Key Insights

- 📅 Peak engagement observed in 2021, with a decline in 2024  
- 🎶 Most listened artists: *The Beatles*, *The Killers*  
- ⏰ Peak listening hours: 8 PM – 12 AM  
- 📉 Engagement dips during early morning hours (6 AM – 12 PM)  
- 🎯 Quadrant analysis classifies tracks based on frequency and listening time  
- 📌 Drill-through enabled for deeper data exploration
